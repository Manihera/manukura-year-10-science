# MANUKURA Year 10 Pūtaiao

A static, mobile-friendly Year 10 Science learning and revision site for MANUKURA.

## Learning areas

- Forces & Motion
- Chemistry
- Body Systems
- Practicals, revision and a mixed end-of-year practice exam

Student lesson ticks and best practice scores are stored only in the current browser. Teacher-verified checkpoints are separate Google Forms links configured in `checkpointLinks` in `script.js`.

## Publishing

The site is designed for GitHub Pages from the repository root on the `main` branch. It has no build step and no ChatGPT Sites dependency.
