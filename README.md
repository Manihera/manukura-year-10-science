# MANUKURA Year 10 Pūtaiao

A static, mobile-friendly Year 10 Science learning and revision site for MANUKURA.

## Learning areas

- Forces & Motion
- Chemistry
- Body Systems
- Practicals, revision and a mixed end-of-year practice exam

## Interactive learning

The 19 lesson sections include 33 curriculum-linked interactive panels. These cover force and motion simulations, randomised calculations, graph interpretation, particle and atom models, pH and separation challenges, muscle and joint activities, responsive SVG labellers, breathing and gas-exchange models, and personal-best mini challenges.

Every activity uses buttons, sliders or large tap targets so it works with a mouse or touchscreen. No activity depends on precise dragging.

Student lesson ticks and best practice scores are stored only in the current browser. Teacher-verified checkpoints are separate Google Forms links configured in `checkpointLinks` in `script.js`.

## Publishing

The site is designed for GitHub Pages from the repository root on the `main` branch. It has no build step and no ChatGPT Sites dependency.
